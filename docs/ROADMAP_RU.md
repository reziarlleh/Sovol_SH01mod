# План развития

Отправная точка — **1.0.0**: обычный заводской цикл, предел температуры 70 °C.
Дальнейшие изменения добавляются по отдельности после проверки базы:

1. Время: 1–12 часов с шагом 1, затем 24, 48, 72, 96.
2. Настройка вентилятора: 10–100 % с шагом 10.
3. Второй датчик температуры/влажности, приоритетный; штатный — резерв/аварийный.
4. Сохранение рабочего состояния при потере питания, продолжение после восстановления.
5. Профили пластиков с понятными именами.

Дополнительное согласованное поведение ошибок: двухтональный сигнал,
код на 5 секунд с возвратом обычной индикации и повторным просмотром.
Пункты плана ещё не являются возможностями версии 1.0.0.

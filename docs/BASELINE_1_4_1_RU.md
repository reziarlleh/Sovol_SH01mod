# Рабочая база Sovol_SH01mod 1.4.1

26.10.2026 владелец подтвердил: «Все правки подтверждаю. Задуманный функционал работает».
Версия 1.4.1 принимается как актуальная рабочая база. Образ после записи не менялся.

Плата G24_V2.1, штатный HC32F005C6PA. Основной SHT4x в камере, штатный AHT20
как резерв, независимый NTC. Температура 40–70 °C, время до 96 часов, вентилятор
10–100%, автоматическое чередование экранов, мигание POWER/однократный сигнал
ошибки и просмотр кода. POWER 2 секунды отменяет цикл, сбрасывает 40 °C/6 ч и
сохраняет выключение после снятия питания. Сбой питания во время RUN возобновляет цикл.
Профили пластиков остаются будущим этапом.

| Показатель | Значение |
|---|---|
| BIN | 13132 байта, 0x00000000..0x0000334B |
| BIN SHA-256 | `f2f45d06887bbdcde11c4ee229265bac1e54325b093c2d708b09fb37b660fd51` |
| HEX SHA-256 | `f2dbe22ab7854f42e9958ebc2c47caeedb4a44bd6a5896b97dec34fdff5aa7ac` |
| Статическая RAM | 248 байт; до вершины стека 3848 байт |
| Журнал | 0x7000..0x7FFF, 8 секторов, SHR1 с CRC/commit/маркером остановки |
| Запись | FT232, Page Erase 26 страниц, Program/Verify 0x787F |

После записи независимо считаны 32 KiB; приложение совпало побайтно,
хвост страницы FF, область 0x3400..0x6FFF сохранена. 93 корректные записи журнала.
Полный readback остаётся локальным: в публичные вложения не включается.

Девять C-наборов и ARM-аудит прошли; HEX/BIN воспроизведены в
[CI исходников](https://github.com/reziarlleh/Sovol_SH01mod/actions/runs/40328620539).
Публикация добавляет актуальные инструкции и утилиты; код MCU и принятые HEX/BIN
сохраняются. Предыдущая база 1.3.1 остаётся доступна как исторический релиз.

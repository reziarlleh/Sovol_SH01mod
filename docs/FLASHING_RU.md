# Прошивка через FT232

Инструкция для заводской платы **G24_V2.1 / HC32F005C6PA**. ROM-загрузчик использует
UART на выводах, подписанных SWDIO/SWDCK; здесь это не протокол SWD.
Стабильный аппаратно подтверждённый релиз:
[v1.4.1](https://github.com/reziarlleh/Sovol_SH01mod/releases/tag/v1.4.1).
Текущие исходники main собирают **1.5.0**, пока без записи и аппаратной приёмки.
Порядок подключения и проверки общий; примеры явного HEX/readback ниже относятся
к 1.5.0. Для стабильного комплекта используйте его файлы версии 1.4.1.

## Комплект и подключение

Распакуйте `Sovol_SH01mod_v1.4.1_windows.zip` в обычную доступную для записи папку.
Он содержит исходники, инструменты проекта и готовый образ в `build/v1.4.1/`.
Компилятор для записи готового HEX не нужен. В PowerShell из папки проекта:

```powershell
.\tools\fetch_tools.ps1 -ProgrammerOnly
```

Загрузка публичная, вход в GitHub и gh не нужны. Выберите фактический **USB Serial
Port** FT232 в диспетчере устройств; COM4 ниже — пример, Bluetooth COM не подходит.
При отсутствии FT232 — [драйвер FTDI VCP](https://ftdichip.com/drivers/vcp-drivers/).

Перед подключением FT232 физически отключите штатные 12 V. Плата питается от
FT232 на 3,3 V; выходные уровни TX/DTR также должны быть 3,3 V.

| FT232 | Колодка платы |
|---|---|
| 3,3 V | 3V3 |
| GND | GND |
| TX | SWDIO / P27 |
| RX | SWDCK / P31 |
| DTR | NRST / RESETB |

Назначения проверены на этом варианте платы; сверка — [HARDWARE_RU.md](HARDWARE_RU.md).

## Перед самой первой заменой заводской прошивки

Один раз сохраните заводскую Flash двумя независимыми полными чтениями:

```powershell
.\tools\open_programmer.ps1 -ComPort COM4 -Readback
```

В GUI проверьте HC32L110x6xx/HC32F005x6xx, 115200, COM FT232 и FlashSize **32K**.
Поле **Hex File пустое**, флажки операций выключены. Нажмите **Upload** и сохраните
результат в `hardware-local/factory-1.hex`. Повторите чтение в `factory-2.hex`.

В XHSC V2.23 **Upload читает MCU → ПК**. При пустом Hex File читаются все 32 KiB.
Красные сообщения о пустом/неверном HEX перед строкой полного чтения относятся
к выбору диапазона; результат должен завершиться успешным чтением, затем сохранением.
**Execute** выполняет выбранные Erase/Program/Verify; это другая кнопка.

```powershell
python .\tools\verify_readback.py .\hardware-local\factory-1.hex --compare-copy .\hardware-local\factory-2.hex --report .\hardware-local\factory-check.json
```

Проверка требует двух полных совпадающих образов без заполнения пропусков.
Храните их локально отдельно от релизов. При обычном обновлении новый factory
backup не требуется: ранее сохранённый оригинал остаётся оригиналом.

## Запись

Закройте GUI перед запуском CLI, чтобы COM был свободен. Сначала можно проверить
конфигурацию без подключения к порту:

```powershell
.\tools\flash.ps1 -ComPort COM4 -DryRun
```

Затем запись готового образа:

```powershell
.\tools\flash.ps1 -ComPort COM4
```

По умолчанию берётся HEX версии из `src/config.h`. Для явного выбора:

```powershell
.\tools\flash.ps1 -ComPort COM4 -HexFile .\build\v1.5.0\sovol_sh01mod_v1_5_0.hex
```

Применяется **Page Erase**, Blank Check, Program, Verify. Журнал `0x7000..0x7FFF`
не входит в образ и не стирается. Не используйте Chip Erase для обычного обновления.
| Версия | Байт | Страниц | Ожидаемый Verify |
|---|---:|---:|---|
| 1.4.1, подтверждена | 13132 | 26 | 0x787F |
| 1.5.0, запись ещё не выполнена | 13400 | 27 | 0xAB35 |

Для 1.5.0 это вычисленная сумма образа, а не результат физической записи.
Скрипт требует свежие Program success и Verify match с правильной суммой;
одного кода завершения 0 недостаточно. Сессия сохраняется в `hardware-local/isp-sessions/`.

Если нужен видимый программатор вместо CLI:

```powershell
.\tools\open_programmer.ps1 -ComPort COM4
```

Конфигурация записи подготовлена, но действие выполняет пользователь кнопкой
Execute. Не запускайте одновременно GUI и CLI. Используйте этот launcher,
чтобы рабочая папка и Config.xml были доступны для записи.

## Независимое контрольное чтение после записи

```powershell
.\tools\open_programmer.ps1 -ComPort COM4 -Readback
```

Нажмите Upload и сохраните новый полный образ как `hardware-local/after-1.5.0.hex`.
Это контроль результата записи, а не повторный заводской backup.

```powershell
python .\tools\verify_readback.py .\hardware-local\after-1.5.0.hex --application .\build\v1.5.0\sovol_sh01mod_v1_5_0.hex --report .\hardware-local\after-1.5.0-check.json
```

Утилита проверяет покрытие всех 32768 байт, совпадение приложения, FF в хвосте
последней страницы и CRC/допустимость записей журнала. HEX и raw BIN поддерживаются.
Отчёт создаётся новым файлом. При наличии предыдущего полного чтения добавьте
`--previous путь-к-предыдущему.hex`: будет сверена область вне приложения/журнала.
Журнал не обязан совпадать с давним снимком: он меняется при сушке.

Закройте программатор, отключите FT232 и только затем подайте штатные 12 V.
Если сохранён RUN, цикл продолжится после проверки датчиков. Ручной POWER на
2 секунды отменяет цикл, возвращает 40 °C/6 ч и сохраняет OFF после снятия питания.
Управление и ошибки — [USER_GUIDE_RU.md](USER_GUIDE_RU.md).

При ошибке соединения проверьте USB Serial Port, общую землю, TX/RX, DTR/NRST,
3,3 V и отсутствие другого процесса, открывшего COM. Перед повтором записи
сохраните журнал неудачной сессии и выясните причину; не меняйте профиль MCU наугад.

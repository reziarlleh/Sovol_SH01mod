# Сборка и прошивка

Windows PowerShell 5.1/7, Arm GNU 15.3.Rel1 (GCC 15.3.1), Python 3 для аудита.
Официальные необходимые DDL/CMSIS-исходники включены в vendor/.

```powershell
.\tools\fetch_tools.ps1
.\tools\build.ps1
.\tools\prepare_host_tests.ps1
.\tools\test.ps1
python .\tools\audit.py
```

Скрипты скачивания проверяют закреплённые размер/SHA-256 инструментов.
ARM-компилятор устанавливается локально в toolchain/, Clang для тестов — в .tools/.
Сборка не требует заводского BIN и не обращается к COM. Версия задана в src/config.h
и включена в бинарник. Результаты находятся в build/v1.0.1/.

Четыре набора компилируют настоящий C-код с моделью периферии: контроллер,
датчик, побитовая шина I²C и LCD. Аудит проверяет HEX/BIN/ELF, векторы, Flash/RAM,
состав модулей, встроенную версию и отсутствие записывающих Flash функций.
CI воспроизводит сборку и контрольные суммы HEX/BIN.

Программатор XHSC V2.23 хранится в приватном релизе v1.0.0 как закреплённый
инструмент; загрузка требует авторизованного GitHub CLI:

```powershell
.\tools\fetch_tools.ps1 -IncludeProgrammer
.\tools\flash.ps1 -ComPort COM4
```

Профиль: HC32L110x6xx/HC32F005x6xx, индекс 33, 115200 бод (индекс 3),
32 KiB Flash, страницы 512 байт. По умолчанию page erase/blank/program/verify.
Сеансы и физические дампы сохраняются только в ignored hardware-local/.
Успех записи требует свежего журнала с точным Verify match. Контрольная сумма
программатора 16-битная, поэтому отдельно выполняется чтение и побайтовая сверка.
Новый полный factory backup при обычном обновлении не требуется, если исходный
уже сохранён. Подключение описано в HARDWARE_RU.md.

Контроль записи и тесты на ПК не заменяют проверку камеры, вентилятора,
нагрева и точности поддержания температуры при питании 12 V.

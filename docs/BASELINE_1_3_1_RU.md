# Рабочая база 1.3.1

2026-10-26 владелец подтвердил текущую конфигурацию фразой:
«Фиксируем работающий конфиг». Версия **1.3.1** принята как рабочая база.

Тег: `v1.3.1`. [Приватный релиз](https://github.com/reziarlleh/Sovol_SH01mod/releases/tag/v1.3.1).
Следующие доработки выполняются в новых версиях; образ этой базы сохраняется.

## Зафиксированная конфигурация

| Параметр | Значение |
|---|---|
| Плата / MCU | G24_V2.1 / заводской HC32F005C6PA |
| Температура | 40–70 °C, шаг 5 °C |
| Длительности | 6, 8, 10, 12, 18, 24, 32, 48, 72, 96 часов |
| Основной датчик | Дополнительный цифровой SHT4x в камере |
| Резерв | Штатный AHT20, запускается только после подтверждённого отказа основного |
| Показания и регулирование | По одному активному цифровому датчику |
| Обработка сбоев | Три попытки основного; последнее корректное значение не старше 3 секунд |
| Возврат с резерва | Три успешных измерения основного подряд |
| Защита | 73 °C по активному цифровому датчику и независимый NTC нагревателя |
| Вентилятор | Включён на 100% при сушке, настройка скорости ещё отсутствует |
| Экран | Температура/влажность ↔ оставшееся время каждые 4 секунды |
| Короткое POWER | Просмотр кода на 5 секунд, повторное нажатие листает коды |
| Уведомление об ошибке | Мигание POWER, обычный короткий звуковой сигнал |
| POWER 2 секунды | Нагрузки, экран, подсветка, LED и звук выключаются; без охлаждения |
| Сбой питания | Автоматическое продолжение активного цикла после проверки датчиков |
| Сохранение | При запуске и раз в минуту, журнал SHR1 `0x7000..0x7FFF` |
| Отмена продолжения | Ручной OFF, авария E1–E5, конец таймера или вход в настройку |
| Профили пластиков | Не добавлены; остаются отложены |

## Воспроизводимость

Исходники приложения соответствуют проверенному CI-коммиту
`080701eb59168224a25c9a76ac459c78f1ce7f29`.
[CI](https://github.com/reziarlleh/Sovol_SH01mod/actions/runs/40318379311) успешен:
восемь C-наборов, ARM-аудит и воспроизводимость HEX/BIN.
Зафиксирован существующий образ, повторная сборка или прошивка для фиксации не выполнялись.

BIN: 11264 байта, SHA-256:
`c94bcbe303a09f84d326f594ecc2eb0c804c8da549e6f13c89a89d744b3f8ed2`.

HEX SHA-256:
`abffc27503e91b6cee74c1d098e3db8bdafcc1f627ecd90aa19b8571945b936a`.

Последняя запись через FT232/COM4 подтверждена Verify `0xE20A` и независимой
побайтовой сверкой. В релиз включаются исходники, BIN/HEX/ELF/MAP, отчёт аудита,
руководство, эта фиксация и SHA-256 вложений. Физические дампы платы остаются локально.

Подтверждение владельца фиксирует функциональную работоспособность текущей базы.
Продолжительность испытаний и инструментальные измерения точности температуры
не сообщались; длительный 96-часовой прогон отдельно не заявляется.
Статический отчёт сборки сохраняется без переписывания его полей аппаратной приёмки.

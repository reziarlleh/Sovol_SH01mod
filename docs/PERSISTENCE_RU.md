# Сохранение состояния 1.4.1

`src/storage.c` хранит температуру, скорость вентилятора, выбранный пресет, остаток секунд и признак
идущей сушки, а также явное выключение устройства. `src/flash_hal.c` выполняет только выровненную запись слова и стирание
сектора внутри `0x7000..0x7FFF`. Используется официальный Flash-драйвер HC32 DDL.
Прерывания на время операции сохраняются/блокируются, затем восстанавливаются;
контроллер Flash блокируется и возвращается в режим чтения даже после ошибки.

## Формат

Восемь секторов по 512 байт, по 25 записей длиной 20 байт (200 записей).
Пять little-endian слов:

| Смещение | Содержание |
|---|---|
| 0 | `0x31524853` (`SHR1`), формат 1; записывается последним |
| 4 | Счётчик последовательности |
| 8 | Биты 0–18: остаток секунд; 19–25: код температуры/скорости; 26–29: индекс пресета; 30: сушка; 31: OFF |
| 12 | CRC32 IEEE от первых трёх слов |
| 16 | Маркер отмены: FF FF FF FF разрешает продолжение, любое другое значение запрещает |

Проверяются CRC, диапазоны, шаг температуры, пресет, остаток не больше пресета
и ненулевой остаток для активной сушки. Одновременные RUN и OFF запрещены. Записи SHR1 версий 1.1.0–1.3.1
загружаются со скоростью 100%. Другие magic не распознаются.
При пустом журнале записываются остановленные значения по умолчанию 40 °C/6 часов.

## Код температуры и вентилятора

При 100% поле 19–25 содержит прежнюю температуру 40, 45, 50, 55, 60, 65, 70:
при OFF=0 запись полностью совместима с 1.3.1. Для 10–90% берётся индекс
`(температура − 40) / 5 * 9 + процент / 10 − 1` (0–62). Индекс отображается
на последовательность кодов 0–68 с пропуском семи старых температурных кодов.
Неиспользованные 69 и 71–127 отклоняются. Декодирование исключает старые коды,
затем делит индекс на 9, получая температуру и скорость. CRC охватывает всё поле.

При возврате к 1.3.1 запись со скоростью ниже 100% будет отклонена старым
декодером. Существующая защита по новейшему committed magic запрещает продолжать
более старый активный цикл. Это сохраняет отмену автовозобновления при откате.
Число слов записи, маркер остановки, адреса и частота checkpoint не изменены.

## Выключение и включение

С 1.4.1 удержание POWER гасит нагрузки/экран/звук, сбрасывает температуру/время
к 40 °C/6 часам, отменяет активную запись и сохраняет начальные значения с
OFF=1, RUN=0. Скорость вентилятора сохраняется.
При загрузке OFF восстанавливается без включения LCD; его инициализация остаётся
тёмной до чтения журнала. Короткое или долгое POWER из OFF включает экран,
сохраняет OFF=0/RUN=0 и оставляет сушку остановленной. После ручного POWER
настройка начинается с 40 °C/6 часов; отменённый остаток не возвращается. После окончания цикла сохраняется
OFF с нулевым остатком; новый запуск через меню предлагает полное время пресета.

Сбой питания во время RUN по-прежнему разрешает автовозобновление после проверки
датчиков. Записи до 1.4.1 читаются с OFF=0: в них не было отдельного признака
ручного выключения. Старые 1.3.1/1.4.0 отклоняют новые OFF-записи по биту 31,
защита по новейшему committed magic запрещает продолжение старого активного цикла.

Если питание исчезнет во время сохранения OFF после успешной отмены RUN,
сушка не возобновится: останется либо старая отменённая запись, либо целая новая
OFF-запись. До commit новой записи восстановление выключенного LCD ещё не гарантируется.

## Обрывы питания

Незавершённая запись без magic пропускается. Перед стиранием следующего сектора
последняя подтверждённая запись остаётся в другом секторе. При новом magic с
повреждённым CRC продолжение более старой активной записи запрещается.
При остановке сначала выключаются нагрузки, затем отдельное слово отменяет
активную запись; даже частичная запись этого слова запрещает продолжение.
Перед отменой журнал пересканируется, включая commit, успевший физически
записаться перед возвратом ошибки драйвером.

Сохранение происходит до запуска нагрева и раз в минуту при сушке. Обрыв питания
между checkpoint может повторить последнюю неполную минуту. Время без питания
не отсчитывается. При восстановлении нагрузки остаются выключенными до свежих
пригодных данных датчиков; неготовность датчиков за 5 секунд вызывает ошибку.
Ошибки записи/отмены дают E5 и не разрешают запуск.

## Проверки и границы

`test_storage.c` проверяет ротацию, CRC, границы и обрывы до, во время и после
каждой записи слова/стирания. `test_resume.c` соединяет настоящий контроллер с
настоящим журналом и моделью Flash: холодный запуск, остаток, температура,
отмена после ручного выключения и аварии. `test_controller.c` дополнительно
проверяет период checkpoint, меню и 96-часовой отсчёт.

При записи 1.1.0 проверено полное содержимое MCU; после её проверки от 12 V
владелец подтвердил работу времени и автовозобновления. В 1.2.0 формат SHR1 и
расположение журнала не меняются. Пригодным источником для возобновления теперь
может быть SHT4x или резервный AHT20; начиная с 1.3.0 перегрев проверяется по
активному цифровому датчику и независимо по NTC. Предупреждение E6 и просмотр
кода через POWER не отменяют сохранённый цикл. Аварии E1–E5 отменяют его.
Проверка модели Flash на ПК остаётся отдельной от физической
проверки устройства. Порядок проверки приведён в инструкции пользователя.

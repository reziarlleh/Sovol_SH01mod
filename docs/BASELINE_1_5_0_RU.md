# Подтверждённая база Sovol_SH01mod 1.5.0

26.10.2026 после записи и проверки владелец подтвердил:
«Всё успешно. Можно фиксировать релиз. Актуализировать описание и документы.
Пока это финал. Если обнаружатся баги, будем патчить».

**1.5.0 принимается как текущая стабильная версия и завершает текущий этап
разработки.** Код MCU и HEX/BIN после приёмки не изменялись. Последующие
исправления выпускаются отдельными патчами 1.5.x. Новые функции не планируются.

## Функционал

Штатная плата G24_V2.1, MCU HC32F005C6PA. Основной SHT4x в камере, штатный
AHT20 после подтверждённого отказа основного, независимая защита NTC.

- Температура 40–70 °C, шаг 5 °C.
- CUSt: 1, 2, 3, 4, 5, 6, 8, 10, 12, 18, 24, 32, 48, 72, 96 часов;
  вентилятор 10–100%, шаг 10%.
- Профили строго CUSt → AbS → ASA → HIPS → PA12 → PCtG → PEtG → PLA → TPU.
  У предустановок вентилятор 100%; [температуры и время](PROFILES_1_5_RU.md).
- M открывает CUSt, ▲ листает, M 2 с запускает предустановку или открывает
  TEMP → TIME → FAN → запуск CUSt. Короткое M в списке отменяет выбор.
  Просмотр/черновик не меняют и не останавливают рабочий цикл.
- ▲ на основном экране показывает цель на 5 с; обычные T/RH и время чередуются
  каждые 4 с. Ошибки: мигание POWER, однократный двухтональный сигнал, просмотр
  коротким POWER на 5 с.
- Автовозобновление RUN после сбоя питания с проверкой датчиков.
- POWER 2 с выключает все нагрузки/индикацию/звук, сбрасывает 40 °C/6 ч,
  сохраняет OFF и действовавший вентилятор. POWER из OFF включает только экран.

## Артефакты и физическая запись

| Показатель | Значение |
|---|---|
| BIN | 13400 байт, 0x00000000..0x00003457 |
| BIN SHA-256 | `a22a52d7b366ab2724326caa1660fd2c217e9303edd8d8d4c7948514b2121076` |
| HEX SHA-256 | `771dc3cffa9c735510f8c950fa6ca2a2d015a00c8e46d5c70da2d89e6395bb7f` |
| Статическая RAM | 252 байта, до вершины стека 3844 байта |
| Журнал | 0x7000..0x7FFF, SHR1, CRC/commit/stop/OFF, checkpoint раз в минуту |
| Запись | FT232/COM4, XHSC V2.23, Page Erase 27 страниц, Program/Verify 0xAB35 |

После записи независимо прочитаны 32768 байт: приложение совпало с BIN побайтно,
хвост до 0x3600 — FF, область 0x3600..0x6FFF сохранилась относительно чтения 1.4.1.
Журнал не стирался, его 192 корректные записи проверены. Заводской backup заново
не снимался. Физические дампы и локальные сессии не входят в Git/релиз.

## Проверки и воспроизводимость

Девять C-наборов прошли: actuators 5049, controller 34348, sensor 269,
dual_sensor 918, sensor_timing 278, bus 1018, lcd 26441, storage 1057279,
resume 19490 проверок. Десять Python-проверок offline readback прошли.
ARM-аудит подтвердил HEX/BIN/ELF, векторы, Flash/RAM, порядок/параметры профилей,
все 15 длительностей и совместимые коды журнала.

[Независимая CI исходников](https://github.com/reziarlleh/Sovol_SH01mod/actions/runs/40352181270)
commit `19520963bdd616bd12425a121d68dd7fbfabed8f` успешна; скачанные HEX/BIN
побайтно совпали с локальными и записанным образом. Хеши исходников в аудитах
совпали. Релизная публикация обновляет описание, документы и комплект,
сохраняя принятые исходники MCU и бинарные образы.

## Использование и публикация

[Релиз v1.5.0](https://github.com/reziarlleh/Sovol_SH01mod/releases/tag/v1.5.0)
содержит Windows ZIP с готовым образом и исходниками, отдельный ZIP исходников,
HEX/BIN/ELF/MAP/аудит, инструкции, XHSC, manifest и SHA256SUMS.
Компиляторы и программатор закреплены по версиям/SHA-256 в [TOOLS_RU.md](TOOLS_RU.md).
[Прошивка](FLASHING_RU.md), [управление](USER_GUIDE_RU.md),
[рекомендуемые доработки](MODIFICATIONS_RU.md).

Предыдущая [1.4.1](BASELINE_1_4_1_RU.md) остаётся исторической подтверждённой базой.
При откате она не понимает новые короткие длительности 1–5 ч и запрещает
возобновление более старого RUN после такой записи. Для текущего использования
рекомендуется 1.5.0.

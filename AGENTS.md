# Sovol_SH01mod

Рабочий корень проекта: `D:/_codex/Sovol_SH01`, язык общения — русский.
Версия 1.0.0 — начальная точка новой разработки. Читать README.md и docs/.
Приложение находится в src/, используется заводской HC32F005C6PA / G24_V2.1.
Код/история/релизы/документация на GitHub должны относиться только к этому проекту.
Старые локальные материалы хранятся отдельно в D:/_codex/Sovol_SH01_archive;
не возвращать их в Git, документацию или Releases. Допустимы сведения о
распиновке и ссылки на проекты-источники. Не публиковать физические дампы платы.

Текущее поручение: собрать и записать 1.0.0 с полным рабочим циклом и пределом
70 °C, затем добавлять отдельные изменения согласно docs/ROADMAP_RU.md.
POWER удерживать 2 секунды. Не добавлять охлаждение после остановки.
Слова владельца «подключено к ПК» означают FT232 3.3 V и отключённые 12 V;
не переспрашивать при явном подключении/поручении прошивать. Нужен фактический
FTDI COM-порт, не Bluetooth. Factory backup уже сохранён в локальном архиве;
не снимать заново перед обычным обновлением. Выполнять page erase/program,
проверять точный Verify match и независимо сверять прочитанные байты.

Сборка tools/build.ps1; тесты tools/test.ps1; аудит python tools/audit.py.
Инструменты восстанавливаются tools/fetch_tools.ps1 и prepare_host_tests.ps1.
Скрипт tools/flash.ps1 использует закреплённый XHSC V2.23 и индекс MCU 33.
Не считать код выхода 0 доказательством записи. Не путать проверку Flash/CI
с физической и тепловой приёмкой. Не вызывать vendor delay10us/delay1ms:
они перенастраивают SysTick. HAL владеет единственным рабочим SysTick_Handler.
Не менять роли SCL=P14/SDA=P15. Обновлять документацию вместе с кодом.

Использовать native Codex memory; не обращаться к retired agent-memory.
Перед существенными поисками/правками использовать RepoWise, затем читать
актуальные исходники; после значимых изменений обновлять индекс.

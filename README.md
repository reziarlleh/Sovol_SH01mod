# Sovol_SH01mod 1.5.0

Рабочая прошивка сушилки **SOVOL / COMGROW SH01**, заводская плата **G24_V2.1**,
микроконтроллер **HC32F005C6PA**. Код на C, сборка Arm GNU GCC. Замена MCU не нужна.

**Стабильная версия 1.5.0 подтверждена владельцем 26.10.2026.**
[Скачать релиз 1.5.0](https://github.com/reziarlleh/Sovol_SH01mod/releases/tag/v1.5.0) ·
[Подтверждённая база](docs/BASELINE_1_5_0_RU.md).
[Управление 1.5.0](docs/USER_GUIDE_RU.md) · [Профили](docs/PROFILES_1_5_RU.md) ·

## Возможности

- Температура 40–70 °C, шаг 5 °C.
- Профили в порядке **CUSt, AbS, ASA, HIPS, PA12, PCtG, PEtG, PLA, TPU**.
- M открывает CUSt, ▲ листает, M 2 секунды запускает предустановку; короткое M
  возвращает основной экран без изменения цикла. Вентилятор предустановок — 100%.
- CUSt: M 2 секунды открывает **TEMP → TIME → FAN → запуск**, ▲ меняет значения.
- Время CUSt: 1, 2, 3, 4, 5, 6, 8, 10, 12, 18, 24, 32, 48, 72, 96 часов.
- Вентилятор CUSt 10–100%, шаг 10%. Просмотр и черновик не изменяют и не
  приостанавливают текущую сушку; тайм-аут отменяет черновик без автозапуска.
- ▲ на основном экране показывает целевую температуру на 5 секунд.
- Внешний I²C SHT4x в камере — основной датчик температуры и влажности;
  встроенный AHT20 используется после подтверждённого отказа основного.
- На экране — только активный датчик; температура/влажность и оставшееся время
  автоматически чередуются каждые 4 секунды.
- Автовозобновление после сбоя питания во время сушки, включая скорость вентилятора.
- **POWER 2 секунды** отменяет цикл, сбрасывает температуру/время к **40 °C / 6 ч**
  и выключает экран, подсветку, светодиоды, звук, вентилятор и нагреватель.
  После возврата питания устройство остаётся выключенным.
- Ошибки: мигание POWER, один двухтональный сигнал при появлении; короткое POWER
  показывает/листает коды на 5 секунд. Ошибка не перекрывает обычный экран постоянно.
- Независимая защита NTC нагревателя и контроль перегрева активного датчика камеры.

Состав и проверка нового меню — [Профили 1.5.0](docs/PROFILES_1_5_RU.md);
[состояние и дальнейший план](docs/ROADMAP_RU.md).

## Начало работы

Для подтверждённого стабильного образа скачайте `Sovol_SH01mod_v1.5.0_windows.zip` из релиза и распакуйте.
Архив содержит HEX/BIN, исходники, инструкции и утилиты. Компилятор для записи готового
HEX не нужен. Из распакованной папки в PowerShell:

```powershell
.\tools\fetch_tools.ps1 -ProgrammerOnly
```

Далее следуйте [инструкции по прошивке](docs/FLASHING_RU.md): проверьте MCU,
подключение FT232 и питание 3,3 V. Обычное обновление сохраняет журнал настроек.
GitHub CLI и вход в GitHub для скачивания публичного комплекта не нужны.

Текущие исходники main собирают 1.5.0. Для сборки:

```powershell
.\tools\fetch_tools.ps1
.\tools\build.ps1
.\tools\prepare_host_tests.ps1
.\tools\test.ps1
python -m unittest discover -s tests -p test_readback_tools.py
python .\tools\audit.py
```

Результаты: `build/v1.5.0/sovol_sh01mod_v1_5_0.{hex,bin,elf,map}`.
HEX/BIN совпадают с записанным и подтверждённым владельцем образом.
1.5.0 завершает текущий этап разработки; обнаруженные ошибки исправляются патчами
1.5.x. Предыдущая 1.4.1 сохранена в истории и релизах.

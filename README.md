# Sovol_SH01mod 1.0.1

Прошивка сушилки SOVOL / COMGROW SH01 для заводской платы **G24_V2.1**
с микроконтроллером **HC32F005C6PA**. Исходники на C, сборка Arm GNU GCC.

Версия 1.0.0 — отправная точка разработки: обычный заводской рабочий цикл
с увеличенным пределом настройки температуры до **70 °C**.

- Настройка температуры 40–70 °C с шагом 5 °C.
- Время 6–12 часов с шагом 1 час, отсчёт от запуска.
- Штатный цифровой датчик камеры и отдельный NTC нагревателя.
- Числовые температура/влажность, оставшееся время, штатные кнопки и LCD.
- Нагрев регулируется по температуре камеры с независимым контролем NTC.
- Вентилятор работает в сушке; POWER 2 секунды выключает нагрузки и экран.

Сборка, тесты на ПК и контроль содержимого Flash подтверждаются отдельно
от проверки датчика и тепловой работы устройства.

Структура: `src/` — приложение и HAL; `vendor/` — необходимые файлы HC32 DDL/CMSIS;
`tests/` — исполняемые C-тесты; `tools/` — сборка и работа с программатором;
`docs/` — документация. Репозиторий приватный.

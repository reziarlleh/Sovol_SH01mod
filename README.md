# Sovol_SH01mod 1.4.1

**1.4.1 собрана, на устройство не записана.** Сушилка продолжает длительный тест
подтверждённой [рабочей базы v1.3.1](docs/BASELINE_1_3_1_RU.md).
Изменения следующего этапа: [вентилятор и сигнал ошибки](docs/FAN_SOUND_1_4_0_RU.md).

Прошивка сушилки SOVOL / COMGROW SH01 для заводской платы **G24_V2.1**
с микроконтроллером **HC32F005C6PA**. Исходники на C, сборка Arm GNU GCC.

Версия 1.0.0 — отправная точка разработки: обычный заводской рабочий цикл
с увеличенным пределом настройки температуры до **70 °C**.

- Настройка температуры 40–70 °C с шагом 5 °C.
- Время: 6, 8, 10, 12, 18, 24, 32, 48, 72, 96 часов; отсчёт от запуска.
- Автовозобновление с сохранёнными температурой, скоростью вентилятора и остатком времени после сбоя питания.
- Дополнительный SHT4x в камере — основной; штатный AHT20 — аварийный резерв.
- Основной имеет три попытки; только подтверждённый отказ запускает резерв и E6.
- Возврат с резерва — после трёх успешных измерений основного подряд.
- Исправный основной датчик единолично задаёт показания и работу; резерв не опрашивается.
- Защита по перегреву активного цифрового датчика и независимая защита NTC нагревателя.
- Числовые температура/влажность, оставшееся время, штатные кнопки и LCD.
- Экран автоматически чередует температуру/влажность и время каждые 4 секунды.
- Ошибки обозначаются миганием POWER; короткое нажатие показывает код на 5 секунд.
- Нагрев регулируется по температуре камеры с независимым контролем NTC.
- Вентилятор: 10–100% с шагом 10%, настройка TEMP → TIME → FAN через M/▲.
- Однократный двухтональный сигнал при появлении ошибки, без повторов пока она сохраняется.
- POWER 2 секунды выключает нагрузки/экран и сбрасывает температуру/время к 40 °C/6 ч.
- После возврата питания ручной OFF сохраняется; включение экрана — только кнопкой POWER.
- Профили пластиков — следующий этап.

Результат: `build/v1.4.1/sovol_sh01mod_v1_4_1.{hex,bin,elf,map}`.
Сборка, тесты на ПК и контроль содержимого Flash подтверждаются отдельно
от проверки датчика и тепловой работы устройства.

Состояние сохраняется при запуске и каждую минуту. После восстановления питания
сушка продолжается автоматически после проверки датчиков. Последняя неполная
минута может повториться; время без питания не вычитается. Ручное выключение,
авария E1–E5, окончание таймера и переход в настройку отменяют автовозобновление.
Предупреждение E6 об основном датчике само по себе сушку не останавливает.

Структура: `src/` — приложение и HAL; `vendor/` — необходимые файлы HC32 DDL/CMSIS;
`tests/` — исполняемые C-тесты; `tools/` — сборка и работа с программатором;
`docs/` — документация. Репозиторий приватный.
